# 系统处理逻辑

## Whatsapp历史消息只精确到分钟的问题
- 这个问题会导致如果如果接收到的消息跟之前自己发送的消息是在同一分钟，会被误认为是老的消息，不会被处理
  - 自己发送消息后，lastTimestamp会更新
  - 如果对方马上发送了新消息，并且在同一分钟，因为没有精确到秒，会被忽略掉
  - 需要做补充处理操作
    - 查看同一分钟内数据库中是否有Hash相同的接收消息，如果没有就认为是新消息
    - 按新消息正常处理，然后把时间设置为lastTimestamp+1秒，并更新lastTimestamp
    - 是否在再次检测时还会被误认为是新消息重复处理？
      - 不会，如果还在同一分钟内，会检查hash是否重复
- 也有可能在同一分钟收到的消息出现乱序
  - 在加载最近消息时，再通过created_time做排序保证

## Whatsapp回车翻译的问题
- 如果内容中有中触发翻译指令
  - 直接按指令进行翻译，然后自动发送
- 如果内容中没有触发翻译指令，但是1分钟内双击空格翻译过，并且当前的内容跟缓存内最近一次的翻译的是匹配的
  - 不需要再次进行翻译，只需要把当前文本框中的内容及之前的原文显示到浮窗并记录到数据库
- 如果内容中没有触发翻译指令，且Without Trigger选项为打开以及侧边翻译浮窗已打开
  - 进行自动翻译
  - 自动翻译时需要检测对方语言是否什么，要自动翻译成对方的语言
  - 如果自己输入的语言和对方一样，也不需要自动翻译
