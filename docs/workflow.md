# 输入框指令触发翻译工作流程

## 双击空格键或回车键触发检测
  - 两个空格键事件间隔不超过400ms，并且空格键之间没有其它事件发生
  - 检查两个空格健之间是否有其它事件是为了避免类似像中文输入法空格上屏时输入速度过快会被误以为是双击空格键
  - 回车键只在Native聊天软件中生效，比如微信、Whatsapp、Discord等  

## 输入框内容获取
- 如果是以下的特殊应用，使用模拟键盘选中复制的方式获取输入框光标前的内容
  - Mail、Notion Mail、Outlook等邮件客户端
  - Web Mail页面（URL中包含常用邮箱的域名）
  - 文本编辑器，比如Notes、Cursor、TRAE等
  - AdsPower特殊应用无法直接获取输入框内容的应用
- 其它正常的应用直接通过系统功能获取输入框内容

## 输入框内容处理
- 如果小于200个字符，直接进行触发命令匹配
- 如果大于200个字符，截取最后50字符进行触发命令匹配（正常情况下触发命令都在输入文本的最后面）
- 如果内容中包含类似#en或@en这样的触发指令，则去除掉触发指令本身，弹出调用翻译接口，弹出翻译状态栏，否则就忽略该次触发

## 调用翻译接口进行翻译
  - 如果输入框内容中有包含触发指令，则先把触发指令提取出来作为翻译后的语言，并把指令从内容中清除
  - 获取到翻译结果后进行解析，准备回填

## 将翻译结果进行回填
  - 如果是特殊应用，已经通过模拟键盘事件把内容选中了，直接粘贴替换
  - 如果是正常应用，模拟键盘全部选中输入框内容，然后将翻译结果粘贴进去完成替换
