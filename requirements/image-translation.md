# 实现截图翻译功能

## 截图选择要翻译的区域
- 用户使用快捷键 Cmd+Shift+S 呼出截图翻译功能，然后用户可以用鼠标选中需要翻译的区域
- 截图用户选中区域的图像，然后压缩后保存到本地目录，格式为PNG，方便后续用户查看
- 然后把截取的图像然后转成Base64的形式
- 快捷键用户可以在Settings中进行自定义
- 需要尽可能的减少传输内容的大小，截取的图像要进行最大化的压缩，但是必须保证清晰度

## 调用翻译接口
- 调用/translate接口，使用流式翻译
- 请求参数中增加一个类型字段type[text|image]字段
- 如果type类型为image，那么text字段对应的内容就是为图像的base64内容，图像格式默认为png
- 示例如下：
```json
{
    "type": "image",
    "text": "xxxx",
    "to": "en",
    "stream": true,
    "user_id": "123@gmail.com",
    "environment": { 
        "os_version": "10.15.7",
        "app_version": "1.0.0",
        "locale_id": "en_US"
    }
}
```

- 返回结果示例如下（markdown格式）：
```
原文内容

翻译内容

扩展解释

背景知识 
```

## 显示翻译的结果
- 需要创建一个通用的对话框，后续如果用户想单独查询某个词时，也可以呼出，像ChatGPT那样进行对话
- 将图像缩略图显示在发送记录中，用户可以点开查看大图
- 流式显示接收到的内容，并对Markdown内容进行渲染
- 内容显示完毕后，用户可以在对话框中追加提问，像Folloup Question功能一样
