# 故障排除指南

## 问题：程序运行一段时间后无法触发翻译

### 症状
- 输入 `#@en` 或类似指令后按空格键，没有反应
- 程序刚启动时工作正常，但运行一段时间后失效
- 选中翻译功能仍然正常工作

### 可能原因和解决方案

#### 1. 空格键事件监听失效
**原因**: 空格键事件可能被系统或其他应用程序拦截，导致无法触发翻译。

**诊断方法**:
1. 菜单栏 → 调试 → 测试空格键捕获
2. 菜单栏 → 调试 → 显示状态（查看空格键事件计数）

**解决方案**:
1. 菜单栏 → 调试 → 重启事件监听
2. 如果问题持续，重启应用程序

#### 2. 事件监听器失效
**原因**: macOS 的事件监听器可能在系统休眠、权限变化或长时间运行后失效。

**解决方案**:
1. 点击菜单栏图标 → 调试 → 重启事件监听
2. 或者重启应用程序

#### 3. 辅助功能权限问题
**原因**: 系统可能撤销了辅助功能权限。

**解决方案**:
1. 打开系统设置 → 隐私与安全性 → 辅助功能
2. 确保应用程序已被授权
3. 如果已授权但仍有问题，尝试移除后重新添加

#### 4. 焦点元素获取失败
**原因**: 某些应用程序的输入框可能无法被正确识别。

**解决方案**:
1. 尝试点击输入框确保获得焦点
2. 在不同的应用程序中测试（如记事本、浏览器等）

### 调试工具

#### 使用内置调试功能
1. **测试空格键捕获**: 菜单栏 → 调试 → 测试空格键捕获
   - 专门测试空格键事件是否被正确捕获
   - 如果测试失败，说明空格键监听有问题

2. **测试触发器**: 菜单栏 → 调试 → 测试触发器
   - 在输入框中输入测试内容（如 `hello #@en`）
   - 点击此选项查看是否能检测到触发器

3. **测试Discord触发器**: 菜单栏 → 调试 → 测试Discord触发器
   - 专门针对Discord的触发器测试

4. **显示状态**: 菜单栏 → 调试 → 显示状态
   - 查看权限状态、事件监听器状态、事件计数等信息
   - 重点关注"Space Key Events"计数

5. **强制健康检查**: 菜单栏 → 调试 → 强制健康检查
   - 立即执行系统健康检查

6. **重置计数器**: 菜单栏 → 调试 → 重置计数器
   - 重置事件计数器，便于观察新的事件

7. **查看日志**: 菜单栏 → 调试 → 打开控制台
   - 搜索应用程序名称查看详细日志

#### 诊断步骤
1. **第一步**: 检查状态
   - 菜单栏 → 调试 → 显示状态
   - 查看"Space Key Events"是否为0或很少

2. **第二步**: 测试空格键
   - 菜单栏 → 调试 → 测试空格键捕获
   - 按几次空格键，看是否能捕获到

3. **第三步**: 测试触发器
   - 在输入框中输入: `测试文本 #@en`
   - 按空格键
   - 如果没有反应，点击菜单栏 → 调试 → 测试触发器

4. **第四步**: 重启监听
   - 如果上述测试失败，点击菜单栏 → 调试 → 重启事件监听

### 常见问题

#### Q: 空格键测试失败但其他键正常
A: 这表明空格键事件被特别拦截了：
- 检查是否有其他应用程序占用空格键
- 尝试重启事件监听
- 检查系统快捷键设置

#### Q: 在浏览器中无法工作
A: 浏览器环境需要特殊处理，确保：
- 浏览器支持（Chrome、Safari）
- 输入框获得焦点
- 尝试在不同网站测试

#### Q: 系统休眠后无法工作
A: 这是已知问题，解决方案：
- 程序会自动检测并重启事件监听
- 手动重启：菜单栏 → 调试 → 重启事件监听

#### Q: 特定应用程序中无法工作
A: 某些应用程序可能有特殊的输入处理机制：
- 尝试在标准应用程序中测试（如记事本）
- 检查应用程序是否有特殊的安全限制

### 预防措施

1. **定期检查**: 程序每30秒自动进行健康检查
2. **权限监控**: 自动检测权限状态变化
3. **自动恢复**: 检测到问题时自动尝试重启事件监听
4. **空格键监控**: 专门监控空格键事件捕获状态

### 获取帮助

如果问题仍然存在：
1. 收集状态信息：菜单栏 → 调试 → 显示状态 → 复制到剪贴板
2. 执行空格键测试：菜单栏 → 调试 → 测试空格键捕获
3. 查看控制台日志中的错误信息
4. 记录问题发生的具体情况（使用的应用程序、输入内容等）

### 日志关键词

在控制台中搜索以下关键词可以快速定位问题：
- `[LOG] Health check` - 健康检查信息
- `[LOG] Space key event detected` - 空格键事件捕获
- `[LOG] ERROR` - 错误信息
- `[LOG] Event tap` - 事件监听状态
- `[LOG] Trigger detected` - 触发器检测结果
- `[LOG] No focused element` - 焦点元素问题
- `[LOG] Space Key Test` - 空格键测试结果
